Embroidery Needle Guide: Which Needle for Which Thread & Fabric?

Published 2025 — EmbroideryConvert Team

Using the wrong needle is like driving with a flat tire — everything suffers. Here's how to match needles to your thread and fabric.

Needle Sizes Explained

Needle sizes use two numbers (e.g., 75/11). The first (75) is metric, the second (11) is American. Higher number = thicker needle.

  • 60/8: Very fine — silk, organza, fine thread
  • 65/9: Fine — lightweight fabrics, 60wt thread
  • 75/11: Standard — most embroidery, 40wt thread
  • 80/12: Medium-heavy — denim, canvas, dense designs
  • 90/14: Heavy — caps, leather, thick thread

Needle Types

  • Sharp (regular point): Woven fabrics (cotton, linen, denim)
  • Ballpoint: Knits (t-shirts, jerseys) — slides between fibers instead of piercing
  • Metallic: Larger eye, special coating — for metallic thread (reduces breakage)
  • Topstitch: Extra-sharp, larger eye — for thick threads or visible stitching
  • Embroidery (universal): Slight ballpoint — general purpose, most common

Thread and Needle Pairing

  • 40wt rayon/poly: Size 75/11 embroidery needle
  • Metallic thread: Size 80/12 metallic needle
  • Thick cotton (30wt): Size 90/14 topstitch needle
  • DMC 6-strand (machine): Not recommended — hand embroidery only
