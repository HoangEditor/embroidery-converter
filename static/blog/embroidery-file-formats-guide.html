Why so many formats?

Unlike PDFs or JPEGs, embroidery files contain machine instructions: stitch coordinates, thread changes, trims, color sequences. Each manufacturer designed their own format optimized for their hardware. DST uses relative movements (compact). PES adds color metadata. EXP separates design from machine commands.
