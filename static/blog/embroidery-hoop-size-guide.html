Embroidery Hoop Size Guide: What Fits Your Machine? (All Brands)

Published June 02, 2025 — EmbroideryConvert Team

Different machines support different hoop sizes. Here's the comprehensive reference for every brand.

Brother Hoop Sizes

  • 4x4 (100x100mm): Standard on entry-level machines (PE535, PE545)
  • 5x7 (130x180mm): Most popular mid-range (PE800, PE900, Innov-is series)
  • 6x10 (160x260mm): Larger home machines (Stellaire XE1, XJ1)
  • 8x12 (200x300mm): Top-end Brother (Luminaire, Stellaire XE2)

Janome Hoop Sizes

  • 5.5x7.9 (140x200mm): MC500E, MC550E
  • 6.7x7.9 (170x200mm): MC12000, MC15000
  • 9.1x11.8 (230x300mm): MC14000, CM17

Commercial Machine Hoops

  • Tajima/Barduan: 12x12, 14x14, 16x16 tubular — and custom sizes up to 24x24
  • Melco: Up to 16x20 with Fast Frames
  • Ricoma: Standard 12x8, optional 12x12

Does File Format Affect Hoop Size?

Yes — some formats store hoop size metadata. PES and JEF include it. DST does not. When converting to DST, our converter preserves dimensions but the machine won't warn you if the design exceeds the hoop.
